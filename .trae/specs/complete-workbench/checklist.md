# Checklist

## 真实数据接入
- [x] `imports/` 目录随项目自动创建
- [x] CSV / JSON / TXT 三种格式均可导入并解析为统一记录结构
- [x] 同一联系人的多行记录被合并为单个会话
- [x] 客户意向摘要流程读取的是导入的真实数据，产物内容与导入数据一致
- [x] `_generate_local()` 随机生成逻辑已删除
- [x] 无导入数据时任务以 `failed` 结束并给出"请先导入 <date> 的聊天记录"提示，不产生任何假记录

## 访问认证与安全
- [x] `WORKBENCH_PASSWORD` 为空时，所有接口不校验，前端无登录界面
- [x] 设置密码后，未携带 `X-Auth-Token` 的业务接口返回 401
- [x] 携带正确令牌时业务接口正常返回，令牌比较为常量时间
- [x] WebSocket 连接在设置密码时校验 `?token=`，错误令牌被拒
- [x] 文件下载在设置密码时校验 `?token=`，直链错误令牌返回 401
- [x] `/health` 始终开放（用于存活探测）

## 通用任务编排
- [x] `capabilities.py` 注册了 `chat_summary` / `file_ops` / `chat` 三个能力
- [x] `coordinator.py` 路由不再包含硬编码的 `_detect()` 分支逻辑
- [x] 无本地模型时，按关键词打分命中能力，两条原流程行为不变
- [x] 无匹配能力时回复可用能力清单而非静默走通用对话
- [x] 新增能力无需改动 `coordinator.py` 路由代码

## UI 体验
- [x] 进度历史面板可展开，展示状态/耗时/错误，失败任务高亮
- [x] 文本/Markdown 文件可在页面内预览
- [x] 图片文件可在页面内直接渲染
- [x] 消息搜索可按关键字过滤当前视图
- [x] "加载更早"可通过 `before` 参数分页拉取历史

## 文档与示例
- [x] `samples/` 提供 CSV 与 JSON 示例导出文件
- [x] 新项目可一键"载入示例数据"并完整跑通摘要流程
- [x] `README.md` 包含导入格式、认证、能力扩展示例
- [x] 《项目修改记录文档.md》已按规范登记本轮条目

- [x] 设置密码后前端登录、消息收发、文件下载、WebSocket 实时同步均可用
